## 1 前置：软件安装与版本确认

先用下面命令确认版本，**JDK 必须是 8**（SpringBoot 2.3.5 对 JDK 11+ 兼容性差，容易踩坑）。

| 软件 | 版本要求 | 检查命令 | 期望输出 |
|---|---|---|---|
| JDK | **1.8**（必须） | `java -version` | `java version "1.8.x"` |
| Maven | 3.3 以上 | `mvn -v` | `Apache Maven 3.x` |
| MySQL | 5.6 以上 | `mysql --version` | `MySQL 5.7/8.0` |
| Redis | 任意 | `redis-cli ping` | `PONG` |

> 没装的话：JDK8 用 `winget install EclipseAdoptium.Temurin.8.JDK`；MySQL 用 `winget install Oracle.MySQL`；Redis 在 Windows 可用 Memurai 或 Redis for Windows。装完重启终端再验证。

## 2 建数据库（3 步）

关键提醒：**真正的 SQL 在 `docs/docker/mysql/` 下**，`docs/db/` 里的是占位文件（内容只有一句"请参考 docker/mysql"），导错就白忙。

1. 确认 MySQL 已启动（服务里找 MySQL 服务，或 `net start mysql`）。
2. 导入建库建表脚本（**自动创建 dblog 库 + 22 张表**）：

```bash
cd /c/Users/qinqingze/Desktop/DBlog
mysql -u root -p < docs/docker/mysql/dblog.sql
```

3. 导入初始数据（文章、管理员账号、菜单等）：

```bash
mysql -u root -p < docs/docker/mysql/init_data.sql
```

4. 验证（应看到 22 张表）：

```bash
mysql -u root -p -e "use dblog; show tables;"
```

> 也可以用 Navicat / DataGrip 直接打开这两个 SQL 文件执行，效果一样。若你的 MySQL root 密码不是 `root`，先改配置（见第 4 步）或导入时用它。

## 3 启动 Redis

- Windows 启动 Redis 后，用 `redis-cli ping` 验证返回 `PONG`。
- 本项目 Redis 用于缓存和 Shiro 会话，**没启动会导致登录失败或启动报错**。

## 4 检查配置（application-center.yml）

配置文件：`blog-core/src/main/resources/config/application-center.yml`。默认值如下，按你本机实际情况核对：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 数据库地址 | `127.0.0.1:3306/dblog` | 库名固定 dblog |
| 数据库账号 | `root / root` | 密码不是 root 就要改 |
| Redis 地址 | `127.0.0.1:6379` | database=1 |
| Redis 密码 | 空（已被注释） | 本地 Redis 无密码则不用动 |

> 若你的数据库密码不是 `root`，**推荐用环境变量**而不是改文件（避免把密码提交到 git）：
> `set ONEBLOG_DATASOURCE_PASSWORD=你的密码`（CMD）或 `export ONEBLOG_DATASOURCE_PASSWORD=你的密码`（Git Bash）

1. 进入 CodeArts 项目「DBlog」→ 左侧 **代码 > 代码托管**。
2. 点 **新建仓库** → 选 **导入仓库** → 来源选 **GitHub**。
3. 填 GitHub 仓库地址 `https://github.com/qinlove-hub/DBlog.git`，按提示授权。
4. 导入完成后，仓库里能看到完整代码与提交历史。

1. CodeArts 代码托管里新建一个**空仓库**，拿到仓库地址。


## 9 常见坑

1. **JDK 不是 8**：编译报 `不支持的类文件版本` 或启动异常 → 装 JDK8 并设 `JAVA_HOME`。
2. **SQL 导错文件**：`docs/db/*.sql` 是占位，必须用 `docs/docker/mysql/*.sql`。
3. **Redis 没启动**：启动报连接拒绝、或后台登录一直失败 → 先 `redis-cli ping` 确认 PONG。
4. **数据库密码不对**：报 `Access denied for user 'root'` → 用环境变量 `ONEBLOG_DATASOURCE_PASSWORD` 覆盖。
5. **日志路径是 Linux 路径**：`application-dev.yml` 里日志和 Tomcat 目录写的是 `/var/tmp/oneblog/...`，Windows 上会落到当前盘根的 `\var\tmp\`，一般能自动创建；若报权限错，改成 `C:/temp/oneblog` 即可。
6. **端口被占**：8443 或 8085 被占用 → 换端口或关掉占用进程（`netstat -ano | findstr 8443`）。
7. **Maven 依赖下载慢**：配阿里云镜像（`~/.m2/settings.xml` 加 `<mirror>`），否则第一次构建很慢。
