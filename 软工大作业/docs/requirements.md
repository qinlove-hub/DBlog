# 个人博客项目需求文档

> 版本：v0.1（初稿）　编写：秦庆泽 / 吴凯阳　日期：2026-10-23
> 依据：《软件工程-敏捷DevOps开发方法》大作业 V1.1 的「1.2 大作业要求」「1.4 评分标准」，以及《个人博客大作业-M1-kickoff》第 3 节接口检查单。

## 1 项目概述

### 1.1 项目背景

本课程要求以敏捷 DevOps 方法完成一个「个人博客」系统的完整开发过程，并在华为云 DevCloud + ECS 上走完需求、规划、开发、构建、部署、流水线的全流程。为在有限周期内既保证流程完成度、又体现自主开发能力，本项目采用「二次开发 OneBlog(DBlog) 打底 + 自研 1~2 个特色功能」的实现路线。

### 1.2 项目目标

1. 提供一个可用的个人博客系统，具备登录、发表文章、评论等核心功能。
2. 在华为云 DevCloud 上完整留痕需求管理、代码托管、构建、部署、流水线各环节。
3. 通过 1~2 个自研特色功能体现二次开发改造深度。

### 1.3 范围界定

- **范围内**：用户登录、文章增删改、评论、文章列表/分类/标签、后台管理，以及特色功能「暗黑模式切换」「文章点赞」。
- **范围外**：多用户付费订阅、全文搜索引擎、第三方社交登录、移动端 App 等，均不在本期实现。

## 2 技术选型

### 2.1 二次开发对象

本项目基于开源博客系统 **OneBlog（项目代号 DBlog，com.zyd.blog v2.3.6）** 二次开发，技术栈如下：

| 层次 | 技术 | 说明 |
|---|---|---|
| 后端框架 | SpringBoot 2.3.5 | 主框架 |
| 语言 / 运行时 | Java 8 | 与 OneBlog 原始要求一致 |
| 数据库 | MySQL 5.6+ | 业务数据存储 |
| 缓存 | Redis | 会话、缓存、点赞计数 |
| 权限 | Apache Shiro | 登录认证与 RBAC 权限 |
| 模板引擎 | Freemarker | 前台/后台页面渲染 |
| 前端 | Bootstrap 3 + jQuery | 页面样式与交互 |
| 构建 | Maven 多模块 | blog-core / admin / web / file / codegen |

> 版本约束：JDK 8、SpringBoot 2.3.5、MySQL 5.6+、Redis 为硬约束，避免后续构建与部署阶段因版本不匹配返工。

### 2.2 特色功能技术路线

| 特色功能 | 实现思路 | 涉及模块 |
|---|---|---|
| 暗黑模式切换 | 前端引入 CSS 变量主题，提供日/夜两套配色，通过本地存储记忆用户偏好 | blog-web |
| 文章点赞 | 新增点赞接口与数据表，Redis 计数 + MySQL 落库，前端异步请求防重复点赞 | blog-core + blog-web |

## 3 用户角色

| 角色 | 说明 |
|---|---|
| 游客 | 未登录用户，可浏览文章、查看文章详情、发表评论 |
| 作者（博主） | 登录后发表、编辑、删除文章，管理评论 |
| 管理员 | 通过后台管理分类、标签、文章、评论与系统配置 |

## 4 用户故事

用户故事格式统一为「作为 [角色]，我想要 [功能]，以便 [价值]」。优先级定义：**P0** = 作业明确点名的核心功能；**P1** = 博客基础要素；**P2** = 特色功能与改造。

### 4.1 P0 核心功能（登录 / 发文 / 评论）

#### US-01 用户登录

作为**作者**，我想要**使用账号密码登录博客后台**，以便**发表和管理我的文章**。

- 验收标准：输入正确账号密码后成功进入后台；错误密码给出明确提示且不泄露账号是否存在；登录状态在会话有效期内保持。

#### US-02 发表文章

作为**作者**，我想要**撰写并发布一篇新文章**，以便**向读者分享内容**。

- 验收标准：输入标题、正文（支持 Markdown）、分类、标签后可成功发布；发布后文章在首页列表可见；空标题或空正文时阻止发布并提示。

#### US-03 编辑文章

作为**作者**，我想要**修改已发布文章的标题和正文**，以便**更正或更新内容**。

- 验收标准：进入编辑页可回显原文内容；保存后前台立即展示修改后的版本；无编辑权限的用户无法访问编辑入口。

#### US-04 删除文章

作为**作者**，我想要**删除不再需要的文章**，以便**保持博客内容整洁**。

- 验收标准：删除操作有二次确认；确认后文章从列表移除且详情页不可再访问；删除不可逆，不提供回收站。

#### US-05 发表评论

作为**游客**，我想要**在文章详情页发表评论**，以便**与作者或其他读者交流**。

- 验收标准：填写昵称和评论内容后可成功提交；提交后评论在文章下方展示；空内容或超长内容被拦截并提示。

### 4.2 P1 基础要素（列表 / 分类 / 标签 / 后台）

#### US-06 文章列表展示

作为**游客**，我想要**在首页看到按时间倒序排列的文章列表**，以便**快速浏览最新内容**。

- 验收标准：首页默认展示最新文章，含标题、摘要、发布时间；支持分页，每页条数合理；点击标题进入详情页。

#### US-07 文章分类浏览

作为**游客**，我想要**按分类筛选文章**，以便**集中阅读某一主题的内容**。

- 验收标准：点击某分类后展示该分类下全部文章；分类侧边栏或导航可见；无文章的分类显示空状态提示。

#### US-08 文章标签浏览

作为**游客**，我想要**按标签查找文章**，以便**发现跨分类的相关内容**。

- 验收标准：点击某标签展示打有该标签的文章；文章详情页展示其所属标签；标签可多个叠加于同一文章。

#### US-09 后台管理

作为**管理员**，我想要**在后台管理分类、标签、文章与评论**，以便**维护整个博客**。

- 验收标准：后台提供分类、标签、文章的增删改查入口；提供评论的查看与删除入口；未登录或权限不足无法进入后台。

#### US-10 评论管理

作为**作者**，我想要**查看并删除读者评论**，以便**清理垃圾或不当内容**。

- 验收标准：后台评论列表可查看全部评论；可对单条评论执行删除；删除后前台对应评论消失。

### 4.3 P2 特色功能（二次开发改造）

#### US-11 暗黑模式切换

作为**游客**，我想要**在页面上切换日间/夜间主题**，以便**在弱光环境下更舒适地阅读**。

- 验收标准：页面提供明显的主题切换入口；切换后全站配色同步变化；刷新或再次访问时保持用户上次选择（本地记忆）。

#### US-12 文章点赞

作为**游客**，我想要**对喜欢的文章点赞**，以便**表达认可并看到文章受欢迎程度**。

- 验收标准：文章详情页有点赞按钮并显示点赞数；点击后计数 +1 且按钮状态变为已赞；同一用户重复点击不重复计数；刷新后点赞数与状态保持。

## 5 非功能需求

| 类别 | 需求 |
|---|---|
| 性能 | 文章列表查询在常规数据量下 1 秒内响应 |
| 安全 | 密码加密存储；后台接口需登录鉴权；防范 SQL 注入与 XSS |
| 兼容 | 支持主流现代浏览器（Chrome / Edge / Firefox） |
| 部署 | 可在华为云 ECS 上以 Jar 方式部署运行 |

## 6 需求优先级与迭代划分

| 迭代 | 范围 | 优先级 | 对应里程碑 |
|---|---|---|---|
| 迭代 1 | US-01~US-05（登录 / 发文 / 评论核心功能） | P0 | M3 |
| 迭代 2 | US-06~US-10（基础要素）+ US-11~US-12（特色功能） | P1 + P2 | M4 |

## 7 待确认事项

1. 特色功能最终选定「暗黑模式 + 文章点赞」两个，是否调整待团队确认。
2. 后台管理权限：本项目为个人博客，作者与管理员的权限边界是否需要进一步细分。
3. 评论是否需要登录才能发表（当前按游客可评论设计），待与老师或团队确认。
